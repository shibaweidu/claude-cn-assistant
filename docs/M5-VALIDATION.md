# M5 备份恢复与中断处理

日期：2026-11-27。恢复操作只处理本工具受管副本目录，不降级原版 MSIX、不回滚账户或对话。

## 已实现

- 枚举 backups/UUID 与 staging-UUID 目录，读取收据中的版本，计算实际文件总大小、目录时间，显示可恢复性。
- 校验 exe、app.asar、ion-dist.asar 的收据哈希、补丁版本、内置启动/页面脚本和 ASAR 词表注册。拒绝损坏、缺少收据、不兼容补丁版本与链接目录。
- 恢复备份/已完成暂存副本前再次校验，当前 managed 先移到新 UUID 备份，再切入所选副本。恢复后同步汉化页状态。
- 制作失败后可重新校验并启用仍可用的当前副本；启动也从已验证的副本收据恢复状态，不再仅依赖最后一次任务成功。
- 所有制作/恢复切换记录到 localization-transaction.json，阶段 planned、oldMoved、newMoved、complete、rolledBack。事务未完成或损坏时阻止新切换和启动，不自动推断成功。
- 用户从恢复页执行中断恢复：旧副本已移走则校验后恢复旧副本；新副本已切入则校验并完成收据；首次制作的新暂存已验证时可提交。新当前副本损坏时先移到 archive，再恢复已校验旧备份。
- 找不到确定可恢复目录或事务记录损坏时停止，保留文件并说明需要检查数据目录。
- 目录限定为工具直接管理的 UUID 子目录，拒绝路径遍历、当前 managed 归档请求、符号链接与 Windows 重解析点。
- 旧备份或暂存目录可归档到 archive/UUID，写入原相对路径元数据。无递归删除、无自动删除备份；归档不释放磁盘空间。归档后的目录暂需在资源管理器中找回。
- 制作、恢复、归档与安装协调互斥；有 Claude 进程时恢复/归档拒绝，不强杀进程。
- 真实恢复页含刷新校验、当前副本重新启用、中断恢复、版本/大小/状态列表及操作确认。耗时校验在后台线程执行。

## 已验证

- 33 项 Rust 测试通过，1 项上游 macOS 本机资源测试保持忽略。
- 7 项新恢复测试：旧副本保留、损坏拒绝、旧目录移走后中断、新目录切入后中断、首次制作中断提交、损坏新副本归档后恢复旧版、列表区分有效备份与未完成暂存，以及异常路径/损坏收据拒绝（部分场景合并在同一测试中）。
- 故障用例全部使用 tempfile 临时目录与合成 ASAR/非可执行测试文件，不操作用户真实 Claude。
- npm run check、生产前端构建、cargo fmt、cargo clippy（-D warnings）及内嵌桌面构建通过。
- 实际启动桌面应用，打开恢复页；本机当前没有受管副本与备份，正确显示暂无备份，没有伪造恢复成功。

## 限制

- 完整真实副本制作与中文启动尚未验收，因此真实大副本恢复、进程占用、断电后磁盘持久性仍需专用测试账户实测。
- 事务日志原子替换并 sync 文件，但不声称抵抗任意存储设备断电；损坏时停止并保留数据。
- 不自动保留两份后删除其余备份。当前采用手动归档，避免未验收前自动清理用户文件；磁盘回收后续采用明确可恢复的系统回收站方案。
- 本项目不主动改写 Claude 语言配置文件，因此没有虚构语言文件备份/恢复。退出中文副本后可启动原版。页面 shim 的界面偏好和跨版本用户数据兼容性仍需完整实测。
- 收据验证覆盖关键文件和当前内置脚本，不是所有 DLL/资源文件的完整清单验证，也不是防御拥有本机写权限的恶意程序。
- 归档保留原始目录及元数据，不自动恢复归档项到列表。可打开数据目录检查 archive。
